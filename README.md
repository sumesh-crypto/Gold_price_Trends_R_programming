# Gold_price_Trends_R_programming
ANALYZING AND FORECASTING GOLD PRICE TRENDS IN US

Completed an advanced time-series modeling project analyzing daily U.S. gold prices (2000–2021) using ARIMA and GARCH techniques in R (Programming Language) as part of my Master’s in Business Analytics. 

The work focused on evaluating market efficiency, detecting volatility patterns, and forecasting short-term risk dynamics. The final model generated a 21-day volatility forecast and included clear visual insights created in RMarkdown.
